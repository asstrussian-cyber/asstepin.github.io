# Политика конфиденциальности приложения «Привычка+»

**Дата последнего обновления:** 6 ноября 2026 г.

Настоящая Политика конфиденциальности описывает, как приложение «Привычка+» (далее — «Приложение») собирает, использует и защищает информацию пользователей. Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

## 1. Общие положения

1.1. Приложение «Привычка+» разработано для создания и отслеживания полезных привычек, ведения статистики, настройки напоминаний и просмотра прогресса.

1.2. Разработчик: **ASSTEPIN**, e-mail: [asstrussian@gmail.com](mailto:asstrussian@gmail.com).

1.3. Приложение не требует регистрации и не создаёт учётных записей. Все данные хранятся локально на устройстве пользователя.

## 2. Какие данные обрабатывает Приложение

Приложение обрабатывает следующие данные исключительно для обеспечения своей функциональности:

- **Привычки и настройки:** названия, описания, иконки, цвета, категории, теги, частота, цели, напоминания — хранятся локально на вашем устройстве в базе данных приложения (Room).
- **Отметки и статистика:** даты выполнения, значения счётчиков, заметки, статусы (выполнено / пропущено / заморожено), серии — хранятся локально.
- **Фотографии (камера/галерея):** Приложение запрашивает доступ к камере или галерее только для прикрепления фотографии к отмеченной привычке. Файлы сохраняются в защищённом хранилище на вашем устройстве.
- **Напоминания (уведомления):** Приложение запрашивает разрешение на отправку уведомлений для отображения напоминаний о привычках.
- **Настройки оформления:** тема, динамический цвет, вибрация, первый день недели — хранятся локально (DataStore).
- **Резервные копии:** по вашему запросу могут создаваться файлы экспорта (JSON/CSV) и автоматические резервные копии в папке `Downloads/HabitFlow` на вашем устройстве.

Приложение **не собирает и не передаёт** на серверы разработчика содержимое ваших привычек, отметок, фотографий и заметок.

## 3. Рекламные идентификаторы и сторонние SDK

3.1. Для показа рекламы в бесплатной версии Приложения мы используем сторонние рекламные сети (Yandex Mobile Ads с медиацией VK Реклама / myTarget).

3.2. Эти SDK могут собирать обезличенный **рекламный идентификатор устройства (Advertising ID)**, а также технические данные (модель устройства, версия ОС, язык, тип сети) для подбора и показа релевантной рекламы.

3.3. Мы не передаём ваши личные привычки, статистику, фото- и текстовые данные рекламным сетям. Передаётся только обезличенный идентификатор, необходимый для работы рекламного аудита.

3.4. Вы можете сбросить или ограничить использование рекламного идентификатора в настройках вашего устройства (Настройки → Google → Реклама, либо Настройки → Конфиденциальность на устройствах без сервисов Google).

## 4. Передача данных третьим лицам

4.1. **Мы не продаём ваши личные данные.** Ваши привычки, отметки и фотографии не передаются третьим лицам.

4.2. Исключение составляют рекламные SDK (п. 3), которые получают только обезличенный рекламный идентификатор для показа рекламы.

## 5. Разрешения и их использование

Приложение запрашивает следующие разрешения:

- `CAMERA` — для создания фотоснимков и прикрепления их к отмеченным привычкам.
- `POST_NOTIFICATIONS` — для отправки напоминаний о привычках (Android 13+).
- `VIBRATE` — для тактильного отклика при взаимодействии с интерфейсом.
- `RECEIVE_BOOT_COMPLETED` — для восстановления напоминаний после перезагрузки устройства.
- `INTERNET` — для загрузки рекламных объявлений.

Вы можете отозвать эти разрешения в настройках вашего устройства, однако это может ограничить функциональность Приложения.

## 6. Хранение и защита данных

6.1. Данные хранятся в изолированной области приложения на вашем устройстве.

6.2. Удаление Приложения с устройства приводит к удалению всех связанных с ним данных (если вы предварительно не сделали экспорт через Настройки → Экспорт JSON/CSV).

6.3. Автоматические резервные копии хранятся в папке `Downloads/HabitFlow` и не удаляются при удалении Приложения — вы можете удалить их вручную.

## 7. Права пользователя

Вы имеете право:

- В любой момент удалить любую привычку или все данные через интерфейс Приложения.
- Экспортировать данные в формате JSON или CSV в любое время.
- Отозвать разрешения в настройках ОС.
- Запросить информацию об обработке данных по указанному ниже адресу.
