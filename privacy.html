Политика конфиденциальности приложения «КлейСтик»

Дата последнего обновления: 26 октября 2026 г.

Настоящая Политика конфиденциальности описывает, как приложение «КлейСтик» (далее — «Приложение») собирает, использует и защищает информацию пользователей. Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

1. Общие положения

1.1. Приложение «КлейСтик» разработано для создания и хранения заметок, списков задач и голосовых записей.

1.2. Разработчик: ASSTEPIN, e-mail: asstrussian@gmail.com.

2. Какие данные обрабатывает Приложение

Приложение обрабатывает следующие данные исключительно для обеспечения своей функциональности:

  • Текстовые заметки и списки задач: хранятся локально на вашем устройстве в базе данных приложения.
  • Голосовые записи (микрофон): Приложение запрашивает доступ к микрофону только в момент создания голосовой заметки. Аудиофайлы сохраняются в защищённом хранилище на вашем устройстве.
  • Фотографии (камера/галерея): Приложение запрашивает доступ к камере или галерее только для прикрепления изображений к заметкам. Файлы сохраняются локально.
  • Напоминания (уведомления): Приложение запрашивает разрешение на отправку уведомлений для отображения напоминаний о заметках.

3. Передача данных третьим лицам

3.1. Мы не передаём ваши личные данные, заметки, аудио- или фотофайлы третьим лицам.

3.2. Все данные хранятся исключительно на вашем устройстве. Приложение не использует облачные серверы для синхронизации (если вы не используете функцию экспорта/резервного копирования, которая сохраняет файл на ваше устройство или в выбранное вами облачное хранилище).

4. Разрешения и их использование

Приложение запрашивает следующие разрешения:

  • CAMERA — для создания фотоснимков и прикрепления их к заметкам.
  • RECORD_AUDIO — для записи голосовых заметок.
  • POST_NOTIFICATIONS — для отправки напоминаний.

Вы можете отозвать эти разрешения в настройках вашего устройства, однако это может ограничить функциональность Приложения.

5. Хранение и защита данных

5.1. Данные хранятся в изолированной области приложения на вашем устройстве.

5.2. Удаление Приложения с устройства приводит к удалению всех связанных с ним данных (если вы предварительно не сделали экспорт).

6. Права пользователя

Вы имеете право:

  • В любой момент удалить любую заметку или все данные через интерфейс Приложения (корзина, очистка данных).
  • Отозвать разрешения в настройках ОС.
  • Запросить информацию об обработке данных по указанному ниже адресу.

7. Изменения в Политике

Мы можем периодически обновлять настоящую Политику. Актуальная версия всегда доступна по адресу: https://asstrussian-cyber.github.io/asstepin.github.io/privacy.html.
