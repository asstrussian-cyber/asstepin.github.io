# Политика конфиденциальности приложения «Эггомания»

**Дата последнего обновления:** 23 ноября 2026 г.

Настоящая Политика конфиденциальности описывает, какие сведения обрабатываются при использовании приложения «Эггомания» (далее — «Приложение»), для каких целей они используются и какие права есть у пользователя.

Приложение распространяется через магазин RuStore и имеет заявленную возрастную категорию 6+. Рекламные показы в Приложении сохраняются, однако для детской возрастной категории должна использоваться реклама без поведенческой персонализации и соответствующий возрастной режим рекламного SDK.

## 1. Общие положения

**1.1.** Приложение «Эггомания» — казуальная игра-коллекция, в которой игроки открывают виртуальные яйца, получают и собирают героев, выполняют игровые задания.

**1.2.** Разработчик: ASSTEPIN.

**1.3.** Контактный адрес электронной почты: [asstrussian@gmail.com](mailto:asstrussian@gmail.com).

**1.4.** Политика применяется к сведениям, обрабатываемым самим Приложением и используемыми в нём сторонними программными компонентами, в пределах их фактической интеграции.

## 2. Какие сведения обрабатываются

**2.1. Игровые данные.** Количество игровых монет, открытые герои, результаты и состояние заданий, игровой прогресс и настройки (например, уровень звука) сохраняются локально на устройстве пользователя. Разработчик не получает эти сведения на собственный сервер, если в Приложении не включены дополнительные сетевые функции, о которых пользователь будет уведомлён отдельно.

**2.2. Технические сведения и сведения для показа рекламы.** При загрузке и показе рекламы встроенный рекламный SDK может обрабатывать технические сведения, необходимые для работы рекламы, например сведения о приложении и его версии, модели и параметрах устройства, версии операционной системы, языке, IP-адресе, диагностике рекламного запроса и идентификаторах устройства — в объёме, предусмотренном настройками SDK и документацией поставщика.

**2.3.** Разработчик не запрашивает у пользователя имя, фамилию, номер телефона, адрес электронной почты, контакты, сведения о здоровье или точную геолокацию для работы игрового процесса.

**2.4.** Приложение не использует игровой профиль, историю действий или игровые предпочтения для формирования поведенческого рекламного профиля.

## 3. Реклама и сторонние SDK

**3.1.** Для загрузки и показа рекламы в Приложении используется **Yandex Mobile Ads SDK**. В зависимости от конфигурации рекламной интеграции SDK может взаимодействовать с рекламными партнёрами и сетями, подключёнными разработчиком.

**3.2.** В Приложении предусмотрены форматы рекламы с вознаграждением (Rewarded Video) и межстраничная реклама (Interstitial). Наличие рекламы не означает, что пользователь обязан совершать покупку или предоставлять разработчику контактные данные.

**3.3.** С учётом возрастной категории 6+ рекламная интеграция должна быть настроена на показ рекламы без поведенческой персонализации. Для этого разработчик устанавливает в Yandex Mobile Ads SDK соответствующий возрастной режим для пользователей младше 13 лет. Такой режим ограничивает использование данных ребёнка для монетизации в соответствии с документацией SDK.

**3.4.** Рекламные материалы должны соответствовать возрастной категории Приложения и применимым требованиям RuStore. Разработчик не намерен использовать сведения о поведении ребёнка для подбора рекламы.

**3.5.** Поставщик рекламного SDK самостоятельно определяет технические детали обработки данных в рамках своей инфраструктуры. Дополнительная информация доступна в [политике конфиденциальности Яндекса](https://yandex.ru/legal/confidential/) и [документации Yandex Mobile Ads](https://ads.yandex.com/helpcenter/ru/dev/android/quick-start).

**3.6.** В настройках Приложения отсутствует переключатель отключения рекламы. Это не отменяет ограничений на обработку данных и прав пользователя, предусмотренных настоящей Политикой и применимым законодательством.

## 4. Цели обработки и передача сведений

**4.1.** Игровые данные используются для сохранения прогресса и обеспечения игровых функций.

**4.2.** Технические сведения, обрабатываемые рекламным SDK, используются его поставщиком для загрузки и отображения рекламных материалов, обеспечения работы рекламных запросов, предотвращения недействительных показов и оценки технической эффективности рекламы — в пределах функций SDK и его настроек.

**4.3.** Игровой прогресс не передаётся рекламным сетям разработчиком. При этом рекламный SDK может самостоятельно получать технические сведения с устройства в момент использования рекламных функций.

**4.4.** Разработчик не продаёт персональные данные пользователей. Передача сведений рекламному поставщику осуществляется в объёме, необходимом для работы рекламной интеграции и при наличии предусмотренного законом основания.

## 5. Разрешения приложения

В зависимости от версии Приложения и используемых функций могут применяться следующие разрешения Android:

- `INTERNET` — для загрузки рекламных объявлений и сетевых ресурсов, необходимых для работы соответствующих функций;
- `POST_NOTIFICATIONS` — для отправки уведомлений, если эта функция включена и разрешена пользователем;
- `SCHEDULE_EXACT_ALARM` — для точного планирования уведомлений, если такая возможность используется данной версией Приложения.

Фактический перечень разрешений определяется манифестом опубликованной версии Приложения. Пользователь может управлять разрешениями в настройках Android; отзыв разрешения может повлиять на соответствующую функцию.

## 6. Хранение и удаление сведений

**6.1.** Игровой прогресс и настройки хранятся локально на устройстве до удаления данных Приложения, использования функции сброса прогресса или удаления Приложения.

**6.2.** Разработчик не ведёт отдельную серверную базу игрового прогресса пользователя.

**6.3.** Технические сведения, которые получает поставщик рекламного SDK, обрабатываются и хранятся этим поставщиком в соответствии с его документами и применимыми правилами. Разработчик не устанавливает самостоятельно сроки хранения данных в инфраструктуре поставщика и не может удалить их непосредственно с серверов поставщика.

**6.4.** Удаление Приложения удаляет локальные данные, относящиеся к нему, в соответствии с механизмами Android. Оно само по себе не гарантирует немедленного удаления сведений, ранее полученных сторонним рекламным поставщиком.

**7.1.** Пользователь или его законный представитель может обратиться к разработчику, чтобы получить информацию об обработке сведений, сообщить о неточности или задать вопрос о защите данных.

**7.2.** Для удаления локального игрового прогресса можно воспользоваться доступной в Приложении функцией сброса прогресса (если она присутствует в установленной версии) либо удалить данные Приложения в настройках устройства.

**7.3.** Если обращение касается сведений, обрабатываемых рекламным поставщиком, разработчик сообщит известную ему информацию и, при необходимости, направит пользователя к соответствующим каналам обращения поставщика.

**7.4.** Родитель или иной законный представитель ребёнка может направить вопросы, связанные с обработкой данных ребёнка, на адрес [asstrussian@gmail.com](mailto:asstrussian@gmail.com).
