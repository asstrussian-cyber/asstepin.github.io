# Политика конфиденциальности приложения «Эггомания»

**Дата последнего обновления:** 12 ноября 2026 г.

Настоящая Политика конфиденциальности описывает, как приложение «Эггомания» (далее — «Приложение») собирает, использует и защищает информацию пользователей. Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

## 1. Общие положения
1.1. Приложение «Эггомания» — это казуальная игра-коллекция, в которой игроки открывают виртуальные яйца и собирают героев.
1.2. Разработчик: ASSTEPIN, e-mail: [asstrussian@gmail.com](mailto:asstrussian@gmail.com).
1.3. Приложение распространяется через магазин приложений RuStore.

## 2. Какие данные обрабатывает Приложение
Приложение обрабатывает следующие данные исключительно для обеспечения своей функциональности:
- **Игровой прогресс:** количество монет, открытые герои, выполненные задания, настройки (например, выключен ли звук). Эти данные хранятся **локально** на вашем устройстве в базе данных приложения и не передаются на сервер.
- **Рекламный идентификатор (Advertising ID):** Приложение использует сторонние рекламные SDK (Яндекс Мобильная Медиация) для показа рекламы. Эти SDK могут собирать обезличенный рекламный идентификатор устройства, а также технические данные (модель устройства, версия ОС, язык) для подбора и показа релевантной рекламы. Мы не передаём ваши личные данные (имя, e-mail и т.д.) рекламным сетям.

**Приложение не запрашивает доступ к камере, микрофону, контактам или геолокации.**

## 3. Рекламные идентификаторы и сторонние SDK
3.1. Для показа рекламы в бесплатной версии Приложения мы используем **Яндекс Мобильную Медиацию** (Yandex Mobile Ads SDK).
3.2. SDK может собирать обезличенный рекламный идентификатор устройства (Advertising ID) и технические данные для показа рекламы и анализа её эффективности.
3.3. Вы можете сбросить или ограничить использование рекламного идентификатора в настройках вашего устройства (Настройки → Google → Реклама).

## 4. Передача данных третьим лицам
4.1. **Мы не продаём ваши личные данные.** Ваш игровой прогресс не передаётся третьим лицам.
4.2. Исключение составляют рекламные SDK (п. 3), которые получают только обезличенный рекламный идентификатор для показа рекламы.

## 5. Разрешения и их использование
Приложение запрашивает следующие разрешения:
- `INTERNET` — для загрузки рекламных объявлений.
- `POST_NOTIFICATIONS` — для отправки локальных уведомлений (например, напоминание о ежедневном подарке).
- `SCHEDULE_EXACT_ALARM` — для точного планирования уведомлений.

Вы можете отозвать эти разрешения в настройках вашего устройства, однако это может ограничить функциональность Приложения (например, вы не будете получать напоминания).

## 6. Хранение и защита данных
6.1. Данные хранятся в изолированной области приложения на вашем устройстве.
6.2. Удаление Приложения с устройства приводит к удалению всех связанных с ним данных.

## 7. Права пользователя
Вы имеете право:
- В любой момент удалить все данные игры через настройки Приложения (кнопка «Удалить прогресс»).
- Отозвать разрешения в настройках ОС.
- Запросить информацию об обработке данных по указанному ниже адресу.
