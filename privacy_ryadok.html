Политика конфиденциальности приложения «РЯДОК»

Дата последнего обновления: 1 ноября 2026 г.

Настоящая Политика конфиденциальности описывает, как приложение «РЯДОК» (далее — «Приложение») собирает, использует и защищает информацию пользователей. Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

1. Общие положения

1.1. Приложение «РЯДОК» разработано как логическая игра-головоломка («пять в ряд»).

1.2. Разработчик: ASSTEPIN, e-mail: asstrussian@gmail.com.

1.3. Игра является полностью офлайн. Для самой игры не требуется подключение к интернету (кроме показа рекламы).

2. Какие данные обрабатывает Приложение

Приложение не собирает и не передаёт ваши персональные данные (имя, телефон, адрес, контакты).

Вся игровая информация хранится локально на вашем устройстве (в защищённом хранилище приложения) и включает:

  • Текущий игровой прогресс (очки, рекорды, количество ходов).
  • Внутриигровая валюта (монеты), достижения и купленные улучшения.
  • Настройки игры (выбранная тема, звук, отключение бонусных шариков).

Эти данные удаляются при удалении Приложения с вашего устройства.

3. Рекламные идентификаторы и сторонние SDK

3.1. Для показа рекламы в Приложении используется сторонний рекламный SDK (например, Yandex Mobile Ads / Рекламная сеть Яндекса).

3.2. Этот SDK может собирать обезличенный рекламный идентификатор устройства (Advertising ID), а также технические данные (модель устройства, версия ОС, язык интерфейса) для подбора и показа релевантной рекламы.

3.3. Разработчик не передаёт рекламным сетям ваши личные данные (их попросту нет). Передаётся только обезличенный идентификатор, необходимый для работы рекламного аудита.

3.4. Вы можете сбросить или ограничить использование рекламного идентификатора в настройках вашего устройства (Настройки → Google → Реклама или аналогичные настройки в системе).

4. Передача данных третьим лицам

4.1. Мы не продаём и не передаём ваши личные данные третьим лицам.

4.2. Исключение составляют рекламные SDK (п. 3), которые получают только обезличенный рекламный идентификатор для показа рекламы.

5. Разрешения и их использование

Для работы Приложения и показа рекламы запрашиваются следующие разрешения:

  • INTERNET — для загрузки рекламных объявлений.
  • ACCESS_NETWORK_STATE — для проверки наличия интернета перед загрузкой рекламы.

Приложение не запрашивает доступ к камере, микрофону, контактам или геолокации.

6. Хранение и защита данных

6.1. Игровые данные хранятся в изолированной области приложения на вашем устройстве (SharedPreferences).

6.2. Удаление Приложения с устройства приводит к полному удалению всех связанных с ним данных (рекордов, монет, достижений).

7. Права пользователя

Вы имеете право:

  • В любой момент удалить свои игровые данные через настройки Приложения (кнопка «Сбросить рекорд» или очистка данных в настройках ОС).
  • Отозвать разрешения в настройках операционной системы.
  • Запросить информацию об обработке данных по указанному ниже адресу.

Мы можем периодически обновлять настоящую Политику. Актуальная версия всегда доступна по адресу: https://asstrussian-cyber.github.io/asstepin.github.io/privacy.html.
